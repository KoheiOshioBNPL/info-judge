# インフォ・ジャッジ

流れてきた情報を、弁護士のように考える。SNSの投稿を法的思考フォーマットの一つである **DRAAW+C** で分解する、ブラウザで動く情報リテラシー教育ゲームです。

**遊ぶ：** [（GitHub PagesのURL）](https://koheioshiobnpl.github.io/info-judge/)

## 何をするゲームか

投稿を読む → まわりの人に聞き込みをして証拠を集める（ノーマルは質問を選ぶ、ハードは自分で質問を書く） → 関わる法律・ガイドライン・規約・社会規範を調べる → DRAAW+Cの6段階で整理する（元の投稿・聞き込み・ルール・自分の選択を常に参照できる） → 結果を見る。

| 段階 | 問い |
|---|---|
| **D** Decision | この投稿をまずどう判断するか |
| **R** Rule | 調べたルールのうち、この件に適用されるものはどれか |
| **A** Arguments（発信側） | 投稿した側の主張と根拠として検討に値するものは |
| **A** Arguments（相手側） | 投稿を疑う側の主張と根拠として検討に値するものは |
| **W** World | 広がったとき社会に何が起きるか |
| **C** Conclusion | すべてを重ねて、どう行動するか |

3つのシナリオ（誤情報・未確認情報・ミスリーディング）はいずれも創作です。各5〜6分。

主な対象は中高生（大人も含む）。自分のスマートフォンとSNSアカウントを持ち始めるのが中学入学前後で、主要SNSの利用規約も13歳以上のため。イージーは中学生以上推奨（案内役の会話、ふりがな、平易な言い換え）、ノーマルは中学生〜高校生推奨、ハードは高校生以上推奨。難易度は3段階（既定はイージー）。**イージー**は案内役のキャラクターが各段階とルールを会話で説明し、難しい漢字にふりがなが付き、4択から1つ選ぶ、**ノーマル**はヒントを押したときだけ出て複数選択、**ハード**はヒントなしで各段階を自分の言葉で書いてから選択肢に進み、書いた内容が結果に残ります（授業・グループ向け。同じシナリオをイージーかノーマルで一度解くと開きます）。

最後の行動で何を選んだかによって、その後の物語が変わります。最初の判断には登場人物がその場で反応し、地震のシナリオでは母からの着信を模したカウントダウンが判断を急かします。3本通すと、自分が選んでしまった弱い論拠の一覧と称号が出ます。

採点は真偽を当てたかではなく、証拠を集めてから判断したか、適用されるルールを選べたか、両側の論拠を根拠のあるものだけで組み立てられたか、証拠で判断を改められたか、で行います（100点満点。詳細は `SCORING_SPEC.md`）。

## ファイル

- `index.html` — ゲーム本体。HTML一枚、外部ライブラリなし。ブラウザで開くだけで動きます
- `SCORING_SPEC.md` — 採点仕様書（実装と同一のロジック）
- `SCENARIO_SOURCES.md` — 3シナリオの元になった公開情報と改変箇所

## 出典

DRAAW+Cは、書籍『法教育の教え方と学び方 クリティカル・シンキングのすすめ』（コリン・シール著、太田勝造監訳、堀口愛芽紗・大塩浩平訳、弘文堂、2023年。原題 *Thinking Like a Lawyer*）において、コリン・シール氏がthinkLawプログラムで用いている法的思考フレームワークです。

## ライセンス

シナリオ本文、キャラクター、コードはすべてオリジナルです。教育目的での利用・改変を歓迎します。シナリオはコードから分離した `SCENARIOS` 配列で定義しているので、同じ形式で4本目を足すことができます。
